# Bar Chart — Visualize Data with a Bar Chart

freeCodeCamp Data Visualization certification project.

## What it shows

United States GDP by quarter, 1947–2015, from the official freeCodeCamp
dataset:
`https://raw.githubusercontent.com/freeCodeCamp/ProjectReferenceData/master/GDP-data.json`

## How to run

Open `index.html` in a browser (serve the folder with any static server,
e.g. `python3 -m http.server`), or host it live. D3.js is loaded from a CDN.

## Tests

The freeCodeCamp test bundle (`bundle.js`, included at the end of
`<body>`) runs the Bar Chart test suite against this page.
